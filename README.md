# High School Assessment: Space Invaders

This repository contains the source code for a classic Space Invaders game, developed as part of my high school assessment task. I uploaded this project to fulfill my submission requirements and share the code for grading.

## How to Run the Game (Windows)

To play the game, follow these instructions:

1. **Keep files together:** Ensure both the `space invaders.py` file and the `Run Space Invaders.bat` file are downloaded and saved in the **exact same folder**. 
2. **Launch the game:** Double-click the `Run Space Invaders.bat` file to automatically launch and run the Python game.
